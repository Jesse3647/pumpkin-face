# Visual reference set

These 13 PNGs were generated by Pumpkin Face's deterministic capture mode at 1280×720 using Godot 4.7.1 Mono, the Compatibility renderer, and an Apple M3 Pro GPU.

The accepted look is the hand-carved performance pass: asymmetric sockets and lid closures, an irregular nose and stepped grin, uneven cavity walls, elongated shadow pupils, and a shared cream-to-amber candle source.

Regenerate them only for an intentional rendering change:

```sh
godot-mono --path src/PumpkinFace.Display -- \
  --capture-dir="$PWD/captures/reference"
```

Use a separate capture directory and `--compare-dir` for routine regression checks. The accepted luma RMSE threshold is `0.035`; see the root README for the complete command and exit codes.
